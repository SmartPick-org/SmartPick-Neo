# 트래블로그 SKYPASS 신용카드  
연회비: 국내 48,000원 / 해외 48,000원  
전월 실적: 없음  

## 대한항공 마일리지 적립 (Travel/airline_mileage) — 포인트적립 0.067%  
국내·외 가맹점 1,500원 당 1마일리지 적립  
- 월 적립한도: 없음  
⚠ 주의사항: 공과금, 교육비, 상품권, 선불카드 충전, 부동산 임대료, 무이자할부 제외  

## 해외서비스 수수료 면제 (Travel/overseas_fee) — 청구할인 100%  
외화 하나머니 결제 시 해외서비스 수수료 및 국제브랜드 수수료 면제  
- 해외 ATM 인출 시 수수료 면제  
⚠ 주의사항: 신용결제 시 수수료 부과 (해외서비스 0.2%, 국제브랜드 1.0%)  

## 기타 혜택  
- 해외결제 방식 선택 가능 (외화 하나머니/신용결제)  
- 외화 하나머니 잔액 부족 시 원화 하나머니 자동 충전  
- 해외 ATM 인출 시 외화 하나머니 잔액 즉시 차감  
- 해외원화결제서비스(DCC) 사전 차단 가능  
- IC칩 비밀번호(PIN) 등록 필요 (일부 해외 가맹점)  
- 연회비 반환 시 잔여기간 일할 계산  
- 부가서비스 3년 이상 유지 (단, 특정 사유 시 변경 가능)
