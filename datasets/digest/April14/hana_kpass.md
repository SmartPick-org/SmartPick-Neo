# K-패스 하나 신용카드  
연회비: 국내 17,000원 / 해외 17,000원  
전월 실적: 50만원 이상 (100만원 이상 시 일부 혜택 상향)  

## 대중교통 (Traffic/transit) — 청구할인 10%  
버스, 지하철 10% 청구할인  
- 50만원 이상 100만원 미만: 월 1만원 한도  
- 100만원 이상: 월 2만원 한도  
⚠ 후불교통카드 매출 건만 적용, 시외버스/고속버스/교통카드 충전금 제외  

## 드럭스토어 (Shopping/drugstore) — 청구할인 10%  
다이소, 올리브영 10% 청구할인  
- 50만원 이상: 일 1,000원 월 1만원 한도  
⚠ 오프라인 결제만 적용, 대형시설물 입점점포/배달앱/상품권/선불카드 제외  

## 커피 (Food/coffee) — 청구할인 10%  
스타벅스, 커피빈 10% 청구할인  
- 50만원 이상: 월 5,000원 한도  
⚠ 대형시설물 입점점포/배달앱/상품권/선불카드 제외  

### 기타 혜택  
- 해외결제 시 국제브랜드수수료(Mastercard 1.0%) + 해외서비스수수료(0.2%) 부과  
- DCC 차단 서비스 제공  
- IC칩 비밀번호(PIN) 등록 필요 시 확인 필수  
- 부가서비스 3년 이상 유지 (단, 특정 사유 시 변경 가능)
